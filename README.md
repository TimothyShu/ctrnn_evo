# ctrnn-evo

Evolutionary optimization of Continuous-Time Recurrent Neural Networks (CTRNNs) using JAX.

## Installation

**Requirements:** Python 3.10+

### CPU (default)

```bash
pip install -e .
```

### GPU (CUDA 12)

```bash
pip install -e ".[cuda]"
```

### Development

```bash
pip install -e ".[dev]"
```

## Running Tests

```bash
pytest
```
